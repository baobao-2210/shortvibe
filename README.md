# ShortVibe - Nền tảng chia sẻ Video ngắn

Dự án ứng dụng video ngắn ShortVibe với kiến trúc đa nền tảng:
- `backend/`: NestJS + PostgreSQL + Prisma ORM (API Server & Database)
- `web/`: Web App (ReactJS) *(Giai đoạn tiếp theo)*
- `mobile/`: Mobile App (ReactJS + Capacitor) *(Giai đoạn tiếp theo)*

Xem chi tiết hướng dẫn thiết lập và khởi chạy Database tại [backend/README.md](file:///d:/HKDN_MOBLIEAPP/ShortVibe/backend/README.md).
